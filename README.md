# Posno Flowers — St. Petersburg Heritage Site

A responsive, editorial static website for the historical St. Petersburg business **Posno Flowers**.

## Live site

GitHub Pages target: https://prithiraj.github.io/Posno_Flowers_Inc/

## Why this version is heritage-first

Research indicates that the historical POSNO FLOWERS, INC. corporation is inactive and the former 6647 Central Ave location is not an active Posno storefront. The implementation therefore does **not** invent or publish current products, prices, ordering, hours, phone numbers, delivery promises, reviews, social profiles, or active-location claims.

See [`DESIGN_PLAN.md`](DESIGN_PLAN.md) for the full evidence baseline, design system, accessibility/performance approach, and acceptance criteria.

## Stack

- Semantic HTML
- Modern CSS
- Vanilla JavaScript
- Optional Three.js progressive enhancement, loaded from jsDelivr
- Real licensed Unsplash photography
- GitHub Pages deployment through GitHub Actions

No build step is required.

## Local preview

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Commercial relaunch checklist

Before converting this into an active florist website, verify and replace/add:

- current ownership / right to use the Posno Flowers name;
- current operating address;
- current phone and email;
- current opening hours;
- real catalog and prices;
- delivery areas and policies;
- current services;
- real current reviews with permission/source attribution;
- active social accounts;
- owner-controlled Posno photography;
- appropriate active `Florist` / `LocalBusiness` Schema.org data.
